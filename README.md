## ✨ Tentang Project

Portfolio pribadi yang dibangun dengan **HTML, CSS, dan JavaScript** murni — tanpa framework, tanpa library, performa maksimal. Desain modern minimalis dengan tema gelap dan aksen mint green.

---

## 🖥️ Preview Halaman

| Section | Deskripsi |
|---------|-----------|
| 🏠 **Hero** | Animasi typing, foto profil dengan efek glow & spinning border |
| 👤 **About** | Bio singkat + stats card |
| 🛠️ **Skills** | Frontend, Backend, dan Tools |
| 📂 **Projects** | 4 featured projects dengan tech stack |
| 📬 **Contact** | Form kontak + link sosial media |

---

## ⚙️ Teknologi

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)

- **CSS Variables** — tema konsisten & mudah dikustomisasi
- **Intersection Observer API** — scroll reveal animations
- **CSS Animations** — spinning border, blob morph, floating dots
- **Responsive Design** — mobile-first, breakpoint 680px & 900px
- **No dependencies** — 0 npm, 0 framework

## 🚀 Cara Menjalankan

```bash
# Clone repo
git clone https://github.com/RamaPutra007/Portofolio.git

# Buka di browser langsung
cd Portofolio
# Klik dua kali index.html atau gunakan Live Server di VS Code
```
